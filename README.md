# effect-media

An experimental library for working with images, audio and video with [Effect](https://effect.website).

> [!CAUTION]
> Experimental and pre-1.0, largely written with Claude Code. Nothing is published yet, and the API will change.

The core package, [`@thomasfosterau/effect-media`](packages/effect-media), has its first modules: `Geometry`, `Color`, `MediaType` and `MediaError`. Image decoding, transforms and backends (sharp, wasm, browser) come next. See [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md) to contribute; agents also read [AGENTS.md](AGENTS.md).
